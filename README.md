# afeefa-portfolio

Personal portfolio of Afeefa Albeena Sheikh. Next.js 15 + Tailwind v4, fully static.

- Content lives in `src/data/content.ts` (story, Euron work, projects, toolkit, links).
- The hero process-flow diagram is `src/components/ProcessDiagram.tsx`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Deploy: import the GitHub repo on vercel.com (framework preset: Next.js). Every push to `main` redeploys.
